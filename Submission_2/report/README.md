# IEEE conference report

Main document: `report.tex`. Compiler: pdfLaTeX. Bibliography: BibTeX, using the included unmodified `IEEEtran.bst`. The unmodified IEEEtran v1.8b class is supplied locally.

Upload `Submission_2_Overleaf.zip` as a new project in Overleaf and select `report.tex`. No online project has been created by this package.

The report's numbers come from `results.tex`, generated from the recorded synthetic experiment. The frozen file is included so the Overleaf project requires no Python, hardware, remote assets, or external files.

For a local build, run `bash build.sh` from this folder. In the complete Submission 2 package, this first refreshes the result constants from the saved metrics. In the standalone Overleaf ZIP, it uses the bundled constants. All temporary files go under `.build/`.

The report presents the project as a simulation-based software study. The reference list has been checked by the project team, as confirmed in the project conversation. Source records and earlier access-check history are retained separately in the literature audit.
